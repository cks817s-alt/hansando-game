# 한산도 대첩 — 학익진을 펼쳐라

1592년 7월 한산도 앞바다에서 벌어진 한산도 대첩을 소재로 한 브라우저 해전 게임입니다.
인천 제물포 AI 교육센터 전시용으로 만들었습니다.

- 바로 하기: https://cks817s-alt.github.io/hansando-game/
- 판옥선을 끌어 학익진을 만들고, 함포 일제 사격으로 왜선 73척(4차 공격 + 적장 대장선)을 막습니다.
- 왜선을 잡으면 거북선 돌격이 충전됩니다. 결과 화면에서 역사 퀴즈를 풀 수 있습니다.
- 파일 하나(`index.html`)로 동작하며, 인터넷 없이도 실행됩니다. 효과음은 브라우저에서 직접 합성합니다.
- 아무 입력이 없으면 잠시 뒤 처음 화면으로 돌아갑니다.
