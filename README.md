# 한산도 대첩 — 학익진을 펼쳐라

1592년 7월 한산도 앞바다에서 벌어진 한산도 대첩을 소재로 한 브라우저 해전 게임입니다.
인천 제물포 AI 교육센터 전시용으로 만들었습니다.

- 바로 하기: https://cks817s-alt.github.io/hansando-game/
- 판옥선을 끌어 학익진을 만들고, 배를 돌려 좌현(왼쪽 옆면)의 총통으로 일제 사격해 왜선 73척(4차 공격 + 적장 대장선)을 막습니다.
- 첫 사격 때 이순신 장군의 명령 장면이 나오고, 안개·포연·불타는 배·느린 화면 등 영화 같은 연출이 이어집니다.
- 왜선을 잡으면 거북선 돌격이 충전됩니다.
- 게임이 끝나면 교과서에 실리는 그림 자료(부산진순절도, 동래부순절도, 거북선 그림, 한산도 대첩 기록화, 임진왜란 전개 지도)로 복습 퀴즈를 풀고, 정답과 해설을 바로 확인합니다.
- 결과는 날짜별 **오늘의 순위**에 기록됩니다(이 컴퓨터의 브라우저에 저장).
- 파일 하나(`index.html`)로 동작하며, 인터넷 없이도 실행됩니다. 배경 음악과 효과음은 브라우저에서 직접 합성합니다.
- 아무 입력이 없으면 잠시 뒤 처음 화면으로 돌아갑니다.
